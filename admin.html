Đăng lên GitHub Pages

  1. Nhấn Xuất website để đăng GitHub, tải ZIP và giải nén.
  2. Mở repo GitHub → Add file → Upload files. Tải các file và thư mục bên trong bản giải nén lên thư mục gốc repo; xác nhận commit bằng tài khoản GitHub của bạn.
  3. Vào Settings → Pages → Deploy from a branch → main → /(root), chọn Save.
  4. Đợi GitHub cập nhật rồi mở link website. Những lần sau chỉ cần tải lại bộ file mới và commit.

Để xóa hẳn ảnh cũ khỏi repo, xóa file tương ứng trong thư mục photos trên GitHub. Xuất bản mới bỏ ảnh khỏi thư viện nhưng không tự xóa file cũ trên repo.
